# Домашнее задание к занятию "`Резервное копирование`" - `Туркменов Роман`



### Задание 1
- Составьте команду rsync, которая позволяет создавать зеркальную копию домашней директории пользователя в директорию `/tmp/backup`
- Необходимо исключить из синхронизации все директории, начинающиеся с точки (скрытые)
- Необходимо сделать так, чтобы rsync подсчитывал хэш-суммы для всех файлов, даже если их время модификации и размер идентичны в источнике и приемнике.
- На проверку направить скриншот с командой и результатом ее выполнения

## Выполнение задания:
```bash
rsync -aHAXxv --checksum --delete --exclude='.*/' ~/ /tmp/backup/
```
Разбор параметров команды:

**-aHAXx (Архивный режим +)** - сохраняет права доступа, владельцев, временные метки, символические ссылки (-a), жесткие ссылки (-H), ACL (-A) и расширенные атрибуты (-X), не выходя за пределы одной файловой системы (-x).
**-v (Verbose)** - подробно выводит список обрабатываемых файлов. \
**--checksum (или -c)** - заставляет rsync всегда вычислять хэш-суммы (контрольные суммы) для проверки изменений, даже если размер файлов и время их модификации совпадают. \
**--delete** - удаляет файлы в целевой папке (/tmp/backup), если они были удалены в источнике (обеспечивает точное зеркалирование). \
**--exclude='.*/'** - исключает из синхронизации все скрытые директории (имена которых начинаются с точки).

### Задание 2
- Написать скрипт и настроить задачу на регулярное резервное копирование домашней директории пользователя с помощью rsync и cron.
- Резервная копия должна быть полностью зеркальной
- Резервная копия должна создаваться раз в день, в системном логе должна появляться запись об успешном или неуспешном выполнении операции
- Резервная копия размещается локально, в директории `/tmp/backup`
- На проверку направить файл crontab и скриншот с результатом работы утилиты.

## Решение 
Создаем скрипт в домашней директории
```bash
nano ~/backup.sh
```
Вставляем текст:
```text 
#!/bin/bash

# Пути к источнику и приемнику
SOURCE="$HOME/"
TARGET="/tmp/backup/"

# Создаем директорию бэкапа, если её нет
mkdir -p "$TARGET"

# Полное зеркалирование домашней директории (включая ВСЕ скрытые файлы и папки)
rsync -aHAXx --delete "$SOURCE" "$TARGET"

# Проверка статуса выполнения rsync и запись в системный лог
if [ $? -eq 0 ]; then
    logger -t rsync_backup "STATUS SUCCESS: Backup of $SOURCE to $TARGET completed successfully."
else
    logger -t rsync_backup "STATUS ERROR: Backup of $SOURCE to $TARGET failed!"
fi
```
Даем права на исполнение:
```bash
chmod +x ~/backup.sh
```
Редактирую задачи cron:
```text
crontab -e
```
Вставляю в конец файла строку для ежедневного запуска:
```text
0 2 * * * /home/roman/backup.sh
```

Вывожу содержимое планировщика в файл и читаю его:
```
crontab -l > my_crontab.txt
cat my_crontab.txt
```

Запускаю скрипт, вывожу лог работы:
```
~/backup.sh
journalctl -t rsync_backup
```
