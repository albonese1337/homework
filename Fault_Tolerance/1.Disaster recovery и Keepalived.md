# Домашнее задание к занятию "`Disaster recovery и Keepalived`" - `Туркменов Роман`



### Задание 1
- Дана [схема](1/hsrp_advanced.pkt) для Cisco Packet Tracer, рассматриваемая в лекции.
- На данной схеме уже настроено отслеживание интерфейсов маршрутизаторов Gi0/1 (для нулевой группы)
- Необходимо аналогично настроить отслеживание состояния интерфейсов Gi0/0 (для первой группы).
- Для проверки корректности настройки, разорвите один из кабелей между одним из маршрутизаторов и Switch0 и запустите ping между PC0 и Server0.
- Отправьте получившуюся схему в формате pkt и скриншот, где виден процесс настройки маршрутизатора.

### Описание выполненных действий:

1. **Вход в настройки**: Открыл консоль `CLI` на Router1, ввел `enable` и `configure terminal` для перехода в режим конфигурации.
2. **Выбор порта**: Перешел к настройке правого интерфейса `interface GigabitEthernet0/1`, который смотрит в сторону сервера.
3. **Настройка HSRP и отслеживания**: Включил вторую версию протокола, привязал виртуальный IP-шлюз сервера (`192.168.1.1`), выставил базовый приоритет `50` и активировал режим `preempt`. Затем ввел команду `standby 1 track GigabitEthernet0/0` для отслеживания состояния левого порта (стороны ПК).
4. **Сохранение**: Вышел из режима настройки командой `end` и сохранил конфигурацию в память устройства командой `write`.
5. **Проверка отказоустойчивости**: Запустил бесконечный пинг с `PC0` на `Server0` и удалил кабель между `Router1` и `Switch0`. Переключение на резервный роутер `Router2` прошло успешно — потерялся всего 1 пакет (`Request timed out`), после чего связь восстановилась автоматически.

### Процесс настройки маршрутизатора

```text
enable
configure terminal
interface GigabitEthernet0/1
standby version 2
standby 1 ip 192.168.1.1
standby 1 priority 50
standby 1 preempt
standby 1 track GigabitEthernet0/0
end
write
```
