### Задание 1
- Запустите два simple python сервера на своей виртуальной машине на разных портах
- Установите и настройте HAProxy, воспользуйтесь материалами к лекции по [ссылке](2/)
- Настройте балансировку Round-robin на 4 уровне.
- На проверку направьте конфигурационный файл haproxy, скриншоты, где видно перенаправление запросов на разные серверы при обращении к HAProxy.


### Описание выполненных действий:

Создаем 2 директории http1/http2
```bash
mkdir http1
mkdir http2
```
Создаем в http1 и http2 - index.html. <br>
Для http1:
```bash
cd http1
nano index.html 
```
Вписываем, чтоб могли различать, какой сервер отдает нам ответ:
```text
Server 1 :8888
```
Для http2: 
```bash
cd ../http2
nano index.html 
```
Вписываем, чтоб могли различать, какой сервер отдает нам ответ:
```text
Server 2 :9999
```
Запускаем python сервера:
```bash
python3 -m http.server 8888 --bind 0.0.0.0
python3 -m http.server 9999 --bind 0.0.0.0
```
Установим HAProxy:
```bash
sudo apt update
sudo apt install haproxy
```
Дополняем файл конфигурации HAProxy (в самом конце) /etc/haproxy/haproxy.cfg:
```text
listen web_tcp
    bind :1325
    mode tcp            
    balance roundrobin  
    server s1 127.0.0.1:8888 check inter 3s
    server s2 127.0.0.1:9999 check inter 3s
  ```
Перезапускаем сервис:
```bash
sudo systemctl reload haproxy
```

### Задание 2
- Запустите три simple python сервера на своей виртуальной машине на разных портах
- Настройте балансировку Weighted Round Robin на 7 уровне, чтобы первый сервер имел вес 2, второй - 3, а третий - 4
- HAproxy должен балансировать только тот http-трафик, который адресован домену example.local
- На проверку направьте конфигурационный файл haproxy, скриншоты, где видно перенаправление запросов на разные серверы при обращении к HAProxy c использованием домена example.local и без него.

### Описание выполненных действий:

Создаем директорию http3
```bash
mkdir http3
cd http3
```
Вписываем в index.html, чтоб могли различать, какой сервер отдает нам ответ:
```text
Server 3 :7777
```
Запускаем 3 python сервер:
```bash
python3 -m http.server 7777 --bind 0.0.0.0
```
Дополняем файл конфигурации HAProxy (в самом конце) /etc/haproxy/haproxy.cfg:

```text
listen stats  # веб-страница со статистикой
        bind                    :888
        mode                    http
        stats                   enable
        stats uri               /stats
        stats refresh           5s
        stats realm             Haproxy\ Statistics

frontend example  # секция фронтенд
        mode http
        bind :8088
        #default_backend web_servers
	acl ACL_example.local hdr(host) -i example.local  # Проверяем заголовок Host на совпадение с example.local
	use_backend web_servers if ACL_example.local      # Направляем на бэкенд ТОЛЬКО если домен совпал

backend web_servers    # секция бэкенд
        mode http
        balance roundrobin
        option httpchk
        http-check send meth GET uri /index.html
        server s1 127.0.0.1:8888 check weight 2
        server s2 127.0.0.1:9999 check weight 3
        server s3 127.0.0.1:7777 check weight 4
```
Перезапускаем сервис:
```bash
sudo systemctl reload haproxy
```

### Задание 3*
- Настройте связку HAProxy + Nginx как было показано на лекции.
- Настройте Nginx так, чтобы файлы .jpg выдавались самим Nginx (предварительно разместите несколько тестовых картинок в директории /var/www/), а остальные запросы переадресовывались на HAProxy, который в свою очередь переадресовывал их на два Simple Python server.
- На проверку направьте конфигурационные файлы nginx, HAProxy, скриншоты с запросами jpg картинок и других файлов на Simple Python Server, демонстрирующие корректную настройку.

### Описание выполненных действий:

Настройка nginx:
```
sudo nano /etc/nginx/conf.d/example.local.conf
```

```text
server {
   listen	80;
   server_name	example.local; 

   access_log	/var/log/nginx/example.local-acess.log;
   error_log	/var/log/nginx/example.local-error.log;

   # Если запрос заканчивается на .jpg, Nginx забирает его сам из /var/www/
   location ~* \.jpg$ {
		root /var/www;
   }

   # Все остальные запросы идут в HAProxy
   location / {
		proxy_pass	http://localhost:1325; 
   }
}
```
Проверяем на ошибки и перезапускаем сервис:
```bash
sudo nginx -t
sudo systemctl reload nginx
```

Проверяем отдачу картинок:
```

```
