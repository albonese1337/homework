## Terraform

Terraform выполняет следующие действия:

1. Создаёт две идентичные виртуальные машины с помощью:

```hcl
count = 2
```

2. Создаёт виртуальную сеть и подсеть.

3. Создаёт Target Group и автоматически добавляет в неё внутренние IP-адреса обеих виртуальных машин.

4. Создаёт Network Load Balancer.

Балансировщик:

* принимает входящий трафик на порту `80`;
* направляет его на порт `80` виртуальных машин;
* выполняет HTTP Health Check по пути `/` на порту `80`.

5. Terraform формирует `inventory.ini` для Ansible, передавая в него внешние IP-адреса созданных виртуальных машин.

6. В `output.tf` выводятся:

   * внешние IP виртуальных машин;
   * внутренние IP виртуальных машин;
   * внешний IP балансировщика.

## Ansible

После создания инфраструктуры Ansible подключается по SSH к обеим виртуальным машинам из сформированного Terraform inventory.

Playbook `nginx_setup.yml`:

* ожидает доступности SSH на порту `22`;
* устанавливает пакет Nginx;
* запускает Nginx;
* включает автоматический запуск Nginx при старте системы.

Запуск playbook:

```bash
cd ansible
ansible-playbook nginx_setup.yml
```

После запуска Nginx начинает принимать HTTP-запросы на порту `80`.

## Проверка

После выполнения Terraform и Ansible:

* Network Load Balancer находится в состоянии `Active`;
* обе виртуальные машины в Target Group находятся в состоянии `Healthy`;
* запрос на внешний IP-адрес балансировщика возвращает стандартную страницу Nginx.

Проверка из терминала:

```bash
curl http://158.160.212.47
```

Также внешний IP балансировщика можно открыть в браузере:

```text
http://158.160.212.47
```
